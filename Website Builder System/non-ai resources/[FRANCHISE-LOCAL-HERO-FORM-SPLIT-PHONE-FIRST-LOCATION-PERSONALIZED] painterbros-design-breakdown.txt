PAINTER BROS DESIGN BREAKDOWN
Source: https://www.painterbros.com/
Analyzed: 2026-04-16
Platform: Webflow (custom franchise build)
==================================================

CONTEXT
--------
Painter Bros is a national franchise painting company serving residential and commercial
clients. The site is a franchise platform — the same design system is deployed across
hundreds of local franchise locations, with each location's phone number, zip code coverage,
and service availability dynamically personalized.

This site is a strong reference for:
- Hero split layout: proof/copy LEFT + embedded lead form RIGHT
- Persistent lead capture form in the navigation (sticky across scroll)
- Phone-first CTA strategy for local service businesses
- Location-based JavaScript personalization for franchise networks
- Franchise-to-local architecture (national brand, local execution)
- Blue/gold trust color system for professional service positioning
- Form-in-hero as the primary conversion mechanism above the fold


1. LAYOUT STRUCTURE
-------------------
Section order (top to bottom):

  Sticky Navigation (logo + nav links + embedded mini-form)
  → Hero (split: copy/proof LEFT, lead capture form RIGHT)
  → Stats Strip (500+ reviews, 4.2 stars, 100k+ jobs completed)
  → "Professional Contractors" feature section
  → Partner Logos (Sherwin Williams, etc.)
  → Testimonials
  → Secondary CTA section ("Schedule Your Free Estimate")
  → Franchise CTA ("Be A Part Of Something Bigger")
  → Footer (service links, locations, social icons)

Lead capture is present in THREE locations above the fold:
  1. Sticky nav (condensed form, always visible)
  2. Hero right panel (full form)
  3. Stats strip CTA ("Get a Free Estimate")

The page is designed to capture leads at every scroll position, not just at the hero.


2. HERO SECTION — SPLIT LAYOUT
--------------------------------
The hero is a two-column CSS Grid:

LEFT COLUMN (1fr): Brand promise + copy
  H1: "Your home or Business Perfectly Painted. Get a Free Estimate Today"
  Subhead: "Expert Painters. Honest Pricing. Exceptional Results."
  — Three parallel noun phrases. No verbs. Scannable in under 2 seconds.
  — "Honest Pricing" is a direct objection response (painting industry known for hidden costs).

RIGHT COLUMN (minmax(24rem, .5fr)): Lead capture form
  Header: "Work With Our Experts & Schedule Your FREE Consultation"
  Fields: First Name, Last Name, Email, Phone, Zip Code, Residential/Commercial radio
  Button: "Get My Free Quote"
  — Form is co-equal to content in the hero. Not secondary. Not below the fold.
  — Glassmorphism panel: `background-color: #ffffff80` (50% opacity white) +
    `backdrop-filter: blur(5px)` on dark background image.

Background: Full-bleed WebP painting photography (1920×1080), lazy-loaded.
Hero min-height: 85vh (keeps form visible above fold on all screens).

Formula to copy (local service businesses):
  [Outcome headline] + [3-word trust triplet as subhead]
  → RIGHT PANEL: form with service type radio (Residential/Commercial)
  — Form panel uses glassmorphism to float over background without blocking image.

What this hero deliberately avoids:
  - No decorative hero with a single CTA button far from the fold
  - No "Learn More" as a primary action
  - No hero that requires scrolling to reach a form

```css

  font-family: var(--font--body);      /* Poppins */

  font-size: .8rem;                    /* 12.8px — small body intentional */
  line-height: 1.6;
}
```

Typography logic:
  - Barlow Semi Condensed (condensed heading font) creates high visual weight at large sizes
    without requiring extreme pixel sizes — useful for service site heroics
  - Poppins (geometric sans) for body — clean, modern, high legibility at small sizes
  - 12.8px body text is intentionally small — lets headings dominate visually
  - No decorative fonts. Heading condensed sans + body geometric = professional service standard.

Font pairing to copy:
  [Condensed heading font (Barlow, Oswald, or similar)] + [Geometric body font (Poppins, DM Sans)]
  This pairing is the default "professional local service" typographic choice — use it when
  the business needs to feel credible without being corporate.

8. LOCATION PERSONALIZATION — JAVASCRIPT
-----------------------------------------
The most technically distinctive pattern on the site. Every franchise location has a
hidden `.loc` element with data attributes. JS reads zip codes, matches them to the
user's input (or geolocation), and personalizes phone numbers and copy.

Location data element (hidden):
```html
<div class="loc"
     data-city="Denver"
     data-state="Colorado"
     data-phone="720-555-1234"
     data-zips="80201,80202,80203"
     data-franchiseid="loc-123">
</div>
```

Personalization JavaScript (simplified from source):
```javascript
document.addEventListener('DOMContentLoaded', () => {

  // Build city index from all .loc elements
  const cityIndex = {};
  document.querySelectorAll('.loc').forEach(n => {
    const city  = (n.dataset.city  || '').trim();
    const phone = (n.dataset.phone || '').trim();
    const zips  = (n.dataset.zips  || '').split(',');

    if (!cityIndex[city]) {
      cityIndex[city] = { phone, zips: new Set() };
    }
    zips.forEach(z => cityIndex[city].zips.add(z.trim()));
  });

  // Swap all phone links to local number
  function updatePhoneLinks(phoneNumber) {
    document.querySelectorAll('.link-phone-local').forEach(link => {
      link.textContent = phoneNumber;
      link.setAttribute('href', `tel:${phoneNumber.replace(/\D/g, '')}`);
    });
  }

  // Match zip code to city, update page
  function matchZip(zip) {
    for (const [city, data] of Object.entries(cityIndex)) {
      if (data.zips.has(zip)) {
        updatePhoneLinks(data.phone);
        // Optionally update city name in copy
        document.querySelectorAll('.city-name').forEach(el => {
          el.textContent = city;
        });
        break;
      }
    }
  }

  // Called when user submits zip code in form
  const zipInput = document.querySelector('#zipcode');
  if (zipInput) {
    zipInput.addEventListener('blur', () => matchZip(zipInput.value));
  }
});
```

Hidden tracking fields (auto-filled on form submit):
```javascript
// UTM parameter capture
const urlParams = new URLSearchParams(window.location.search);
document.querySelector('.ppc-source').value  = urlParams.get('utm_source') || '';
document.querySelector('.referer').value     = document.referrer || '';
document.querySelector('.location').value    = detectedCity || '';
```

When to copy this pattern:
  - Any business with multiple locations where phone numbers differ
  - Multi-location service businesses (multiple cities)
  - Franchise networks

Hero image preloading (JS — prevents hero flash):
```javascript
window.addEventListener('DOMContentLoaded', () => {
  const imageElement = document.querySelector('.image-cover.hero-image');
  if (imageElement) {
    const preloadLink = document.createElement('link');
    preloadLink.rel   = 'preload';
    preloadLink.href  = imageElement.src;
    preloadLink.as    = 'image';
    document.head.appendChild(preloadLink);
  }
});
```

Format: All images served as WebP.
Responsive: 5-point srcset (500w, 800w, 1080w, 1600w, 1920w).
Lazy loading on hero image with JS preload — lazy prevents render-blocking, JS preload
ensures the hero image loads early enough to avoid flash.

16. PATTERNS TO COPY — PRIORITY ORDER
---------------------------------------

FOR ANY LOCAL SERVICE BUSINESS (painting, remodeling, landscaping):

Hero split layout (form RIGHT, copy LEFT):
  Use when: primary conversion is a quote/estimate request.
  The form should be visible without scrolling. Don't put it below the fold.
  Glassmorphism panel: `background-color: rgba(255,255,255,0.5); backdrop-filter: blur(5px)`
  Grid: `grid-template-columns: 1fr minmax(24rem, .5fr)`

Service type radio in form:
  Always include Residential/Commercial split if the business serves both.
  This qualifies the lead before it hits the CRM and routes it correctly.

Zip code as required field:
  Enables location routing for multi-location businesses.
  Even for single-location businesses: confirms the lead is in the service area
  before the owner invests time in a quote call.

Phone tel: link pattern:
  ```html
  <a href="tel:+15035550000">(503) 555-0000</a>
  ```
  Display the number as text AND link it. Never make a user copy-paste a phone number.

Stats strip after hero:
  500+ reviews | 4.2 stars | 100k+ jobs
  Three stats, separated by vertical dividers. Inline SVG stars (not icon font).
  Visible above first scroll. Directly reinforces hero claims.

Hidden tracking fields:
  Always include UTM source, referrer, and location in hidden form fields.
  Essential for attributing which marketing channel generates leads.
  ```html
  <input type="hidden" class="ppc-source" name="PPC Source" />
  <input type="hidden" class="referer"    name="Referer" />
  ```

FOR MULTI-LOCATION BUSINESSES:
  Location JS personalization pattern:
  Data attributes on hidden `.loc` elements → JS builds zip-to-phone index →
  Zip input on blur triggers phone number swap across all `.link-phone-local` elements.
  This keeps the static site dynamic without a CMS or server-side rendering.
